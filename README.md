# Website ZEED Briquette Global

Website perusahaan PT. ZEED Continental Trade, perusahaan trading komoditas ekspor briket arang batok kelapa dari Indonesia (nama tampil: ZEED Briquette Global).

Isi website: katalog briket shisha dan BBQ dengan tabel spesifikasi per grade (Premium dan Medium), bentuk briket (Cube, Flat, Dome, Hexa), program private label, data pasar ekspor global, FAQ, dan kanal kontak resmi (WhatsApp, email info@zeedbriquette.com, LinkedIn).

Situs statis satu berkas (HTML, CSS, JavaScript), tayang melalui GitHub Pages.
